# Idioma (i18n)

O host decide o idioma. Os remotes recebem por props e acompanham as trocas.

## Host

```jsx
import { events } from 'vitral'

function trocarIdioma(idioma) {
  document.documentElement.lang = idioma
  events.emit('i18n:idioma', idioma)
}

<Remote name="catalogo" props={{ idioma }} />
```

Passe por props para o remote ter o valor já no `mount`. Emita no barramento para remotes que não recebem props do host.

## Remote React

```jsx
export default reactRemote(function Catalogo({ idioma }) {
  const t = useTraducoes(idioma)
  return <h2>{t('titulo')}</h2>
})
```

## Remote Vue com vue-i18n

```ts
import { createI18n } from 'vue-i18n'
import { vueRemote } from 'vitral/vue'
import { events } from 'vitral'

export default vueRemote(Catalogo, {
  setup(app, ctx) {
    const i18n = createI18n({ legacy: false, locale: events.last('i18n:idioma') ?? 'pt-BR', messages })
    app.use(i18n)
    ctx.events.on('i18n:idioma', (idioma) => (i18n.global.locale.value = idioma))
  },
})
```

A assinatura feita por `ctx.events` é cancelada no unmount.

## Textos de cada remote

Cada remote leva as próprias traduções no build ou baixa da própria origem. Para montar a URL, use `ctx.baseUrl`:

```ts
const mensagens = await fetch(new URL(`i18n/${idioma}.json`, ctx.baseUrl)).then((r) => r.json())
```

Datas e números: use `Intl` com o idioma recebido. Ele já está no navegador e não aumenta o bundle.
